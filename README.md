# 🎮 GameStation

**GameStation** is a curated browser-game portfolio consisting of **18 fully playable games**, all built using **HTML, CSS, vanilla JavaScript, and Bootstrap**.

The project was created to demonstrate strong **frontend fundamentals**, including game-loop logic, state management, input handling, UI structure, and the ability to finish and polish complete systems.

This is a **frontend-only project by design**.

---

## 🧠 Project Purpose

GameStation exists to showcase:
- Clean JavaScript logic without frameworks
- Deterministic, restart-safe systems
- Interactive UI design
- Scope control and project completion
- Technical judgment (what to build — and what not to build)

Rather than building one large game, the project explores **multiple focused mechanics**, each implemented as a self-contained experience.

---

## 🕹️ Games Overview

The site includes **18 games**, grouped by emphasis:

### ⭐ Featured Games
A curated selection highlighting depth, polish, and technical clarity.

- **VoidRunner** — Endless runner with deterministic difficulty scaling  
- **Uncanny** — Perception-based puzzle focused on timing and uncertainty  
- **TimeThief** — Time manipulation game with solo and co-op modes  
- **BrainSplit** — Logic puzzle involving switches, doors, and goals  
- **ScrollQuest** — Action-adventure with feedback-driven combat and smooth camera motion  

### 🧪 More Experiments
Smaller games exploring individual mechanics and ideas:

MirrorDark · MazeFade · GridLock · GravShift · DominoTrigger · ColorClash · CodeBreaker · CipherTrace · ChronoSplit · GlitchSnitch · TapFrenzy · ThoughtSnare · StackHack

All games are playable directly in the browser.

---

## 🛠️ Technologies Used

- **HTML5** — semantic structure and accessibility  
- **CSS3** — custom styling with CSS variables and responsive layouts  
- **JavaScript (Vanilla)** — all game logic, state machines, and input handling  
- **Bootstrap 5** — grid system, components, and responsive utilities  

### Intentionally not used
- No backend / server-side code  
- No databases  
- No authentication or payment systems  
- No frontend frameworks  

This keeps the focus on **frontend logic and interaction**, which is the goal of the project.

---

## 🧩 Design Principles

- **Finish over features** — every game reaches a complete, playable state  
- **Clarity over complexity** — readable logic and predictable systems  
- **Judgment over overengineering** — no fake functionality  
- **Consistency** — shared UI language across the site  

---

## 🌐 Site Structure

- `index.html` — Project introduction and entry point  
- `games.html` — Curated game catalog (Featured + Experiments)  
- `about.html` — Project intent and developer overview  
- `contact.html` — Safe contact information and approximate location  
- `css/style.css` — Global, cohesive styling  
- `Games/` — Individual game folders and files  

---

## 🚀 How to Run

1. Clone or download the repository
2. Open `index.html` in a modern web browser
3. Navigate to **Games** and select any game to play

No build steps or dependencies required.
